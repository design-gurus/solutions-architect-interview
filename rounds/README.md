# Rounds

A solutions architect (SA) loop combines up to six kinds of interview. Each page below explains what one round measures, how it usually runs, and how to prepare for it.

| Round | What it measures | Page |
|---|---|---|
| The whole loop | The order of the stages and how company types differ | [interview-loop.md](interview-loop.md) |
| Architecture design | A design for one customer, with cost and a migration plan | [architecture-design.md](architecture-design.md) |
| Customer discovery role-play | Questions before answers, and objection handling | [customer-discovery-role-play.md](customer-discovery-role-play.md) |
| Presentation | A clear recommendation and answers to hard questions | [presentation.md](presentation.md) |
| Behavioral | Past decisions, conflict, failure, and customer trust | [behavioral.md](behavioral.md) |
| Technical screen | Breadth across six areas of cloud knowledge | [technical-screen.md](technical-screen.md) |

Start with [the interview loop](interview-loop.md) if the stages are new to you. For worked answers to every round, see [Grokking the Solutions Architect Interview](https://www.designgurus.io/course/grokking-the-solutions-architect-interview?utm_source=github&utm_medium=repo&utm_campaign=solutions-architect-interview&utm_content=rounds-readme).
